# التقارير اليومية — ميثم، مساعد مدير التشغيل

سجل يومي لما أنجزته في الشغل.

## طريقة العمل
1. ترسل لـ Claude إنجازاتك بكلامك العادي مع الصور.
2. Claude يرتبها في تقرير احترافي مقسم ويرسله لك تراجعه.
3. تضيف أو تعدل، وبعدها يُحفظ التقرير والصور هنا.

## الاستخدام
```bash
./new-report.sh              # ينشئ تقرير اليوم
./new-report.sh 2026-11-04   # ينشئ تقرير يوم محدد
```

## الهيكل
```
templates/daily-report.md   القالب
reports/YYYY-MM/YYYY-MM-DD.md   تقرير كل يوم، مرتبة حسب الشهر
```

## أقسام التقرير
1. ملخص اليوم
2. الإنجازات
3. مؤشرات التشغيل (KPIs)
4. متابعة الفريق
5. المشاكل والحلول
6. القرارات والاجتماعات
7. أمور معلقة / تحتاج تصعيد
8. خطة بكرة
9. الصور والشواهد
