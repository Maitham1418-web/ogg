# التقارير اليومية — مدير تشغيلي

سجل يومي لما أنجزته في الشغل.

## الاستخدام
```bash
./new-report.sh              # ينشئ تقرير اليوم
./new-report.sh 2026-11-04   # ينشئ تقرير يوم محدد
```

## الهيكل
```
templates/daily-report.md   القالب
reports/YYYY-MM/YYYY-MM-DD.md   تقرير كل يوم، مرتبة حسب الشهر
```

## أقسام التقرير
1. ملخص اليوم
2. الإنجازات
3. مؤشرات التشغيل (KPIs)
4. متابعة الفريق
5. المشاكل والحلول
6. القرارات والاجتماعات
7. أمور معلقة / تحتاج تصعيد
8. خطة بكرة
